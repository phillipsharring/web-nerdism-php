# Modern PHP

Lesson: https://phillipharrington.com/php/modern-php

Enums, readonly classes, constructor promotion, match, named arguments and the
nullsafe operator, in one script. Give it a status:

```
docker run --rm -v "$PWD":/app -w /app php:8.4-cli php order.php paid
docker run --rm -v "$PWD":/app -w /app php:8.4-cli php order.php lost
```
